The gap2 / 12

We built the loop around that missing column

1

Capture

OpenAI-compatible proxy logs every call to a trace store.

2

Fingerprint

Groups calls by task: same system prompt and tools.

3

Grade

Deterministic verdict per trace against an answer key. No model judges a model.

4

Curate

Only verified answers become training rows. Leakage and token-cap guards.

5

Distill

LoRA fine-tune of a small open model on Token Factory.

6

Promote

Shadow the small model, compare, then promote or roll back.

Steps 3 and 4 are the part the platform doesn't have. Everything else reuses Token Factory primitives: inference, files, fine-tuning jobs.

About 1 in 4.5 teacher answers was wrong (22.3%). Without the verdict, all of them would have been training data. The verified set, toolace-verified-v2, has 818 training and 91 validation rows; the longest is 1,792 tokens against a 7,500 cap.

Curating with verdicts5 / 12

Grading without a judge, checked both ways

  • Reads native tool_calls and ToolACE's text format, [Name(k=v), …], including names like Open-High-Low-Close (OHLC) API and keys like from= and $select=.
  • Matches several calls order-insensitively, one-to-one.
  • BFCL mode: each argument lists every acceptable value; invented parameters fail.
  • Network failures count as errors, never as wrong answers.
