A 30B model matches the 235B teacher at function calling

On 450 held-out items across two benchmarks, Qwen3-30B-A3B is statistically indistinguishable from Qwen3-235B-A22B, at roughly a tenth of the latency. Every verdict is a deterministic comparison against an answer key. No model grades another model.

The verdict column

Grading every teacher answer before training on it

Token Factory already logs every completion and Data Lab turns logs into datasets. What a log does not record is whether the answer was right. We added that column: the teacher answered all 1,200 ToolACE training prompts, every answer was graded, and only the correct ones became training data.

Guards on v2: zero prompts shared with the ToolACE eval set (checked by hash; BFCL is a separate source and was not hash-checked); longest row 1,792 tokens against a 7,500 cap (median 626); 246 of the 818 rows are the teacher's own wording, not a copy of the answer key, which is what makes this distillation.

For the presenter

How to say it

Safe to claim

  • “On 450 held-out items, the 30B model is statistically indistinguishable from the 235B model.”
  • “It ties exactly on BFCL, a benchmark it never trained on.”
  • “About an order of magnitude lower latency.”
  • “No LLM-as-judge: every verdict is a comparison against an answer key.”
  • “1 in 4.5 teacher answers was wrong. The verdict column kept them out of training.”

Don't claim

  • “The models are equal.” Say “indistinguishable at this sample size” and give p.
  • An exact speed multiple. Single runs under concurrency gave 18.7× and 8.8×.
  • Any fine-tuned (“pupil”) number. No fine-tuned model has been served yet.
  • That the teacher is better. +3.6 pts with a CI touching zero is not evidence.

Runs: data/evals/ev-f1890ed2.json (ToolACE) and data/evals/ev-faca1a75.json (BFCL). Responses are cached per model and item, so re-running regrades without new API calls. Code: prkshverma09/NebiusHack @ 522463a, 84 tests passing.
